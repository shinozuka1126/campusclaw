## ADDED Requirements

### Requirement: 班级限定混合检索
系统 MUST 先按服务端用户班级过滤知识片段，再融合 BM25 和 TF-IDF 向量余弦排序；问答最多使用前 4 条片段，不得按请求的 class_id 扩大查询。

#### Scenario: 自然语言提问
- **WHEN** 本班已上传包含“磁铁能吸引铁钉，不能吸引木块”的材料，用户询问“磁铁能吸木块吗？”
- **THEN** 能召回对应片段，返回其材料和字符偏移，最多返回 4 个片段

#### Scenario: 跨班请求
- **WHEN** A 班用户提问 B 班独有内容并指定 class_id=2
- **THEN** 检索结果与发送给模型的上下文均不含 B 班片段

### Requirement: 依据原文生成回答
系统 MUST 使用服务端配置的 DeepSeek 服务，按本班检索原文生成简短回答，要求并校验 [n] 引用。原文 MUST 作为不可信资料处理，不能覆盖系统指令。

#### Scenario: 命中并回答
- **WHEN** 本班有相关片段且 DeepSeek 已配置、可用
- **THEN** 返回带有效 [n] 引用的回答及对应原文来源

#### Scenario: 无资料不调用模型
- **WHEN** 本班没有相关片段
- **THEN** 返回“本班资料中没有找到相关内容”，model_called=false，sources=[]
- **AND** 不向模型服务发送请求

#### Scenario: 无效模型引用
- **WHEN** 模型返回不存在的引用编号或没有引用
- **THEN** 返回明确的生成失败，不展示未经验证的回答

### Requirement: 来源可核对
系统 MUST 展示引用材料标题、切片编号、原文区间、原文正文、详情和下载链接；来源路由 MUST 继续校验身份和班级。

#### Scenario: 追溯回答
- **WHEN** 用户查看回答 [1]
- **THEN** 能看到编号为 1 的实际检索片段及原材料链接

### Requirement: 失败路径与身份验证
问答和检索接口 MUST 要求有效 Cookie 或 Bearer 身份；非法问题返回 400；缺少模型密钥/模型名时命中请求返回 503；上游超时或错误返回通用错误，不泄露密钥、token、堆栈、原始上游错误。

#### Scenario: 未登录或非法问题
- **WHEN** 未认证请求接口，或已认证用户发送空白、超长、非字符串问题
- **THEN** 分别返回 401 或 400，不调用模型

#### Scenario: 模型未配置或故障
- **WHEN** 本班检索命中而模型未配置或请求失败
- **THEN** 页面显示配置或重试提示，不能冒充成功回答

### Requirement: 可操作问答页面
系统 MUST 提供知识检索/知识问答页签、发送问题、等待与错误状态，回答和正文以纯文本显示。

#### Scenario: 浏览器提问
- **WHEN** 登录用户进入知识问答并发送问题
- **THEN** 浏览器携带既有 Bearer token（若存在）发起 ask 请求并展示回答和来源，重复点击不会并发提交同一问题
